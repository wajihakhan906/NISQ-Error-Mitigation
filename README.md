# NISQ Measurement Error Mitigation

Measurement error mitigation techniques for noisy intermediate-scale quantum (NISQ) hardware.

## Highlights
- Validated on **IBM Kyoto (127-qubit)** hardware
- Calibration-matrix based readout error correction
- Comparison of raw vs. mitigated measurement distributions

## Tech Stack
Qiskit · IBM Quantum
