# Data

This project does not use an external dataset. All data is generated by running circuits:

- **Calibration data**: `2^n` basis-state preparation circuits (`mitigation.calibration_circuits`) that build the
  readout assignment matrix.
- **Benchmark data**: measurement counts of Trotterized Ising and GHZ circuits (`circuits.py`).
- **Device calibration**: gate/readout errors are read from the backend target (real IBM device or a
  `qiskit-ibm-runtime` fake backend snapshot).

Raw run outputs are written as JSON to `Results/`.
